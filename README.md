# Network Walks Internship – Week 1

## Project Module 1: Cybersecurity Testing Lab Environment Setup

### 1. Project Overview

This project involves setting up a cybersecurity testing lab environment using Oracle VirtualBox and Kali Linux.

The main purpose is to establish a virtual environment for practising cybersecurity, ethical hacking and network security testing.

### 2. Project Objectives

- Install and configure Oracle VirtualBox.
- Download and import Kali Linux.
- Create a custom NAT Network.
- Configure the network subnet as 10.0.0.0/24.
- Assign a static IP address to Kali Linux.
- Establish internet connectivity.
- Enable clipboard and drag-and-drop functionality.
- Configure shared folders.
- Create a virtual machine snapshot.

### 3. Tools and Technologies

| Tool | Purpose |
|---|---|
| Oracle VirtualBox | Virtualisation platform |
| Kali Linux | Cybersecurity testing machine |
| 7-Zip | Extracting compressed files |
| Windows 10/11 | Host operating system |

### 4. Network Configuration

| Parameter | Configuration |
|---|---|
| Network Type | NAT Network |
| Network Address | 10.0.0.0/24 |
| Kali Linux IP | 10.0.0.2 |
| Subnet Mask | 255.255.255.0 |
| Default Gateway | 10.0.0.1 |
| DNS Server | 8.8.8.8 |

### 5. Implementation Steps

1. Download and install 7-Zip.
2. Download and install Oracle VirtualBox.
3. Create a custom NAT Network.
4. Download and import Kali Linux.
5. Configure the Kali Linux network adapter.
6. Assign the required IP address.
7. Test internet connectivity.
8. Enable clipboard and drag-and-drop.
9. Configure the shared folder.
10. Create a virtual machine snapshot.

### 6. Project Evidence

Screenshots will be added to demonstrate the installation, network configuration, IP address verification, connectivity testing and virtual machine settings.

### 7. Learning Outcomes

- Understanding virtualisation technologies.
- Understanding NAT networking.
- Configuring Linux network settings.
- Performing basic network connectivity tests.
- Preparing a cybersecurity testing environment.
